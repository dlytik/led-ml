# Repository Structure

This file documents the directory layout of the LED-ML repository. For end-user documentation and usage examples, see [README.md](README.md).

## Overview

The repository contains the source code for the **led-ml** Python package, along with documentation, tests, and build configuration files.

```
led-ml/
├── led-ml/                    # Python package directory (published to PyPI as 'led-ml')
│   ├── __init__.py
│   ├── setup.py              # Package metadata and dependencies
│   ├── MANIFEST.in           # Package distribution manifest
│   ├── PACKAGE_SETUP.md      # Detailed packaging documentation
│   ├── README.md             # PyPI package documentation
│   └── led_ml/               # Main package source code
│       ├── __init__.py       # Package initialization and exports
│       ├── constants.py      # Configuration constants
│       ├── led_core.py       # Core diagnostics engine
│       ├── led_latency.py    # Latency measurement utilities
│       ├── led_size.py       # Memory footprint analysis
│       ├── led_viz.py        # Visualization tools (text & GIF)
│       └── supported_models.json  # Supported model configuration
│
├── latex/                     # LaTeX documentation
│   ├── main.tex             # Main LaTeX document
│   ├── main.bbl             # Bibliography data
│   └── references.bib       # References
│
├── output/                    # Sample output files
│   ├── mistralai-Mistral-7B-Instruct-v0.3.json
│   ├── openchat-openchat-3.5-0106.json
│   └── Qwen-Qwen2.5-7B.json
│
├── test.py                    # Standalone example and validation script
├── README.md                  # PyPI package documentation (user-facing)
├── DIRECTORY.md              # This file - repository structure reference
├── CONTRIBUTING.md           # Contribution guidelines
├── ISSUES.md                 # Known issues
├── LICENSE                   # License file
└── .gitignore               # Git ignore rules
```

## Key Directories

### `led-ml/` — The Python Package

This is the directory that gets packaged and published to PyPI. When users run `pip install led-ml`, they receive the contents of this directory, with the structure:

```
led_ml/
├── __init__.py
├── constants.py
├── led_core.py
├── led_latency.py
├── led_size.py
├── led_viz.py
└── supported_models.json
```

**Files**:
- `setup.py` - Defines package metadata, version, dependencies, and build configuration
- `MANIFEST.in` - Specifies which data files (like `supported_models.json`) to include in the distribution
- `PACKAGE_SETUP.md` - Detailed documentation for package development and setup

### `latex/` — Documentation

Contains LaTeX source files for technical documentation or papers:
- `main.tex` - Main document
- `references.bib` - Bibliography references
- `main.bbl` - Compiled bibliography

### `output/` — Sample Diagnostics Output

Example JSON files showing the structure of diagnostics data generated by LED-ML:
- Output from different model runs (Mistral, OpenChat, Qwen2)
- These demonstrate the format of captured activation/gradient data

### Root Level Files

- **test.py** - Standalone validation script demonstrating LED-ML usage. Not included in the PyPI package.
- **README.md** - User-facing documentation for PyPI. Focuses on installation and usage.
- **CONTRIBUTING.md** - Guidelines for contributors
- **ISSUES.md** - Known issues and limitations
- **LICENSE** - License information

## Development vs. Distribution

**For Development** (cloning this repo):
- Developers can run `pip install -e led-ml/` to install in editable mode
- Full access to source code, tests, and documentation

**For End Users** (PyPI installation):
- Users run `pip install led-ml`
- They receive only the `led_ml/` package directory contents
- The `test.py`, `latex/`, `output/`, and top-level documentation files are not distributed

## Building and Publishing

To build the distribution package:

```bash
cd led-ml
python setup.py sdist bdist_wheel
```

This creates distribution files in the `dist/` directory that can be uploaded to PyPI.
