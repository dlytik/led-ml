# Output Directory Structure

This file documents the structure and contents of diagnostic output files generated by LED-ML.

## Overview

When running LED-ML diagnostics on a language model, the tool generates:

1. **JSON files** — Structured diagnostic data containing activation and gradient metrics
2. **GIF files** — Visualizations of neuron activation patterns across model layers

## Output Files

### JSON Diagnostic Files

**Format**: `{model_name}.json`

**Example**: `Qwen-Qwen2.5-7B.json`, `mistralai-Mistral-7B-Instruct-v0.3.json`

These files contain complete diagnostic metrics captured during inference on a specific model. The data includes:

- **Model metadata**: Model name, architecture, number of layers
- **Query/Prompt**: The input prompt used
- **Response**: The model's generated output
- **Layer-wise metrics**: For each model layer:
  - Forward activation patterns
  - Gradient/Jacobian patterns (causal sensitivity)
  - Activation counts and statistics
  - Memory footprint per layer
  - Execution latency per hook


**Structure Example**:
```json
{
  "prompt": "What is the color of chlorophyll?",
  "model": "Qwen/Qwen2.5-7B",
  "torch_dtype": "torch.float16",
  "mode": "trajectory",
  "num_layers": 28
  "ten_pct_cnt": 358,
  "layers": [
    {
      "layer_id": 0,
      "forward_activations": [...],
      "Backward_Grads": [...],
      "hook_overhead_ms": 2.34
    },
    ...
  ],
}
```

### GIF Visualization Files

GIF files provide visual representations of neuron behavior across layers. Two types are generated:

#### 1. **standard.gif**

**Content**: Activation patterns for the first 100 neurons across all layers

**Shows**:
- **Forward Pass** (left side): Activation magnitudes during the forward pass
- **Jacobians/Gradients** (right side): Causal sensitivity (gradient influence) for each neuron

**Use Case**: 
- Quick overview of model behavior
- Identifying which layers are most active
- Spotting anomalies in activation patterns

#### 2. **extended.gif**

**Content**: Selective neuron views across all layers

**Shows**:
- **Forward Activations** (top): Top 30% AND bottom 30% of activated neurons (first 10% of total neurons sampled)
- **Jacobians/Gradients** (bottom): Top 30% of most sensitive neurons (first 10% of total neurons sampled)

**Why extended?**:
- Captures both highly active neurons (top 30%) and baseline activity (bottom 30%)
- Shows causal influence of neurons on output (top 30% jacobians)
- Provides nuanced view of model information flow

**Use Case**:
- Detailed analysis of neuron importance
- Understanding which neurons contribute to output decisions
- Research into model interpretability

## Reading the Visualizations

### Character Encoding

- `░` (Light shade) — zero activation/gradient
- `█` (Dark shade) — High gradient
- `▲` (Triangle) — Positive activation point
- '▼' (Down Triangle) - Negative activation point

### Interpreting Patterns

**Horizontal patterns** (across neurons):
- Uniform activity: Layer processes all inputs equally
- Sparse activity: Layer selects specific features
- Dense activity: Layer broadly activates

**Vertical patterns** (across layers):
- Increasing activation: Early layers less active, later layers activate features
- Decreasing activation: Early layer extraction, later layer aggregation
- Peaks/valleys: Specific layers important for certain computations

## Example Workflow

```python
import led_ml
import json
from led_ml import led_viz

# Initialize and run diagnostics
led = led_ml.led_core(mode="trajectory")
response = led.run_model("Your prompt here", model_family="qwen2")
diagnostics = led.get_led()

# Save JSON output
with open("model_diagnostics.json", "w") as f:
    json.dump(diagnostics, f)

# Generate visualizations
led_viz.gif_led(diagnostics)  # Creates standard.gif and extended.gif
led_viz.text_led(diagnostics)  # Print text-based visualization
```

## Analysis Use Cases

### Performance Profiling
- Use JSON data to identify layers with high latency
- Compare latency across different models
- Optimize hook implementations based on measurements

### Memory Analysis
- Examine `total_ram_bytes` to understand memory requirements
- Plan distributed inference strategies
- Profile memory per layer for bottleneck identification

### Model Interpretation
- Use GIF visualizations to understand information flow
- Identify which layers are critical for specific tasks
- Study neuron specialization across layers
- Compare activation patterns between different prompts

### Model Debugging
- Spot unusual activation patterns indicating issues
- Verify gradient flow during backpropagation
- Detect inactive layers or dead neurons

## File Organization

Recommended output structure:
```
output/
├── {model_name}.json              # Diagnostic metrics
├── {model_name}_standard.gif      # Standard visualization
├── {model_name}_extended.gif      # Extended visualization
```

This organization allows easy comparison across:
- Different models
- Different prompts on the same model
- Multiple runs with different configurations
